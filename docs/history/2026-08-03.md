重要な注意点

学生証のICチップに書き込まれたデータは
大学側が暗号化・保護していることがほとんどです。

→ 暗号キーがないと読み取れない
→ 大学の許可なく読み取ることは
　 規約違反・不正アクセスになる可能性がある
現実的な実装方針

方法1：カードID（UID）のみ読み取る（推奨）

暗号化されていないカード固有のIDを読み取り、事前に大学側と連携して登録済みIDと照合する方法です。


学生証をかざす
　↓
カードのUID（固有ID）を読み取る
　↓
事前に登録済みのUID一覧と照合
　↓
一致すれば在校生と判定

方法2：大学システムと連携する

大学のシステム担当者と協力して、正規の方法でデータにアクセスする方法です。

まず確認してほしいこと

1. 学生証の種類を調べる

Androidスマホに NFC TagInfo というアプリをインストールして学生証をかざすと、チップの種類とUIDが確認できます。

https://play.google.com/store/apps/details?id=at.mroland.android.apps.nfctaginfo

2. 表示された情報を教えてください


・チップの種類（FeliCa / MIFARE / ISO14443など）
・UID（カード固有ID）
・読み取れたデータの有無

チップの種類がわかれば、React NativeでのNFC読み取り実装方法を案内できます 😊

import NfcManager, { NfcTech, Felica } from 'react-native-nfc-manager';

// NFC初期化
export async function initNfc() {
  await NfcManager.start();
}

// FeliCaからデータを読み取る
export async function readStudentCard() {
  try {
    await NfcManager.requestTechnology(NfcTech.NfcF); // FeliCa = NfcF

    const tag = await NfcManager.getTag();
    const uid = tag.id; // カードUID

    // ↓ 大学側と連携後にここにシステムコード・サービスコードを追加
    // const SYSTEM_CODE = [0x00, 0x00]; // 大学から取得
    // const SERVICE_CODE = [0x00, 0x00]; // 大学から取得
    // const response = await NfcManager.transceive([...]);

    return {
      uid: uid,
      isEnrolled: await verifyWithServer(uid), // サーバーで照合
    };
  } catch (error) {
    console.error('NFC読み取りエラー:', error);
    return null;
  } finally {
    NfcManager.cancelTechnologyRequest();
  }
}

// UID をサーバー（GAS）で照合
async function verifyWithServer(uid) {
  try {
    const response = await fetch('あなたのGASのURL?action=verify&uid=' + uid);
    const data = await response.json();
    return data.isEnrolled;
  } catch (error) {
    return false;
  }
}

// 在校生判定（Firestoreのuserデータから）
export function isEnrolledStudent(userDoc) {
  // 大学側と連携後にここに判定ロジックを追加
  return userDoc.isEnrolled === true;
}

4. マイページに学生証認証ボタンを追加しておく

javascript
import { initNfc, readStudentCard } from '../utils/checkEnrollment';
import { updateDoc, doc } from 'firebase/firestore';

// MyPageScreen.js に追加
const handleVerifyStudent = async () => {
  Alert.alert(
    '学生証認証',
    'スマホに学生証をかざしてください',
    [
      { text: 'キャンセル', style: 'cancel' },
      {
        text: '認証する',
        onPress: async () => {
          try {
            await initNfc();
            const result = await readStudentCard();

            if (result?.isEnrolled) {
              // Firestoreのユーザー情報を更新
              await updateDoc(doc(db, 'users', auth.currentUser.uid), {
                isEnrolled: true,
                enrolledAt: new Date().toISOString(),
              });
              Alert.alert('認証完了', '在校生として認証されました！');
            } else {
              Alert.alert('認証失敗', '在校生として確認できませんでした');
            }
          } catch (error) {
            Alert.alert('エラー', 'NFC読み取りに失敗しました');
          }
        }
      }

    ]
  );
};

// マイページのUIに追加
