レッスン 1-3：StyleSheet と Flexbox

今回はレイアウトの核心です。React NativeのFlexboxはCSSとほぼ同じですが、デフォルトの挙動が一部違うので整理しましょう。

WebのFlexboxとの違い
	Web CSS	React Native
flex-direction のデフォルト	row（横並び）	column（縦並び）
align-items のデフォルト	stretch	stretch
単位	px % rem	数値のみ（dp）
flex: 1	利用可能な幅を埋める	利用可能なスペースを埋める
主要プロパティ

javascript
// 子要素を横並びにする
flexDirection: 'row'

// 主軸方向の配置
justifyContent: 'center'        // 中央
justifyContent: 'space-between' // 両端に配置
justifyContent: 'flex-start'    // 左/上寄せ

// 交差軸方向の配置
alignItems: 'center'   // 中央
alignItems: 'stretch'  // 引き伸ばす

// 余白
flex: 1  // 残りスペースをすべて埋める
実際に触ってみる

const [count, setCount] = useState(0);

Props とは


javascript
// 親から渡す

  return <Text>{name} - {price}</Text>;
}

レッスン 2-1：React Navigation

React Nativeで画面遷移を実現するには React Navigation というライブラリを使います。Webでいう React Router に近い存在です。

インストール

ターミナルで FleaMarketApp フォルダに移動した状態で以下を実行してください。


bash
npx expo install @react-navigation/native
npx expo install @react-navigation/native-stack
npx expo install react-native-screens react-native-safe-area-context

npx expo install を使うのがポイントです。Expoと互換性のあるバージョンを自動で選んでくれます。

基本的な構造

React Navigationは3つの要素で構成されます。


NavigationContainer   ← アプリ全体を囲むコンテナ
  └── Stack.Navigator ← 画面のスタックを管理
        ├── Stack.Screen（画面A）
        ├── Stack.Screen（画面B）
        └── Stack.Screen（画面C）
実際に触ってみる

まず App.js を以下に書き換えてください。


javascript
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { View, Text, TouchableOpacity, StyleSheet } from 'react-native';

const Stack = createNativeStackNavigator();

// 画面A：商品一覧
function HomeScreen({ navigation }) {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>商品一覧</Text>
      <TouchableOpacity
        style={styles.button}
        onPress={() => navigation.navigate('Detail')}
      >
        <Text style={styles.buttonText}>商品詳細へ →</Text>
      </TouchableOpacity>
    </View>
  );
}

// 画面B：商品詳細
function DetailScreen({ navigation }) {
  return (
    <View style={styles.container}>
      <Text style={styles.title}>商品詳細</Text>
      <TouchableOpacity
        style={styles.button}
        onPress={() => navigation.goBack()}
      >
        <Text style={styles.buttonText}>← 戻る</Text>
      </TouchableOpacity>

    </View>
  );
}

// アプリ本体
export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator>
        <Stack.Screen name="Home" component={HomeScreen} options={{ title: '商品一覧' }} />
        <Stack.Screen name="Detail" component={DetailScreen} options={{ title: '商品詳細' }} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#f5f5f5',
    alignItems: 'center',
    justifyContent: 'center',
    gap: 16,
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#333',
  },
  button: {
    backgroundColor: '#FF6B6B',
    paddingVertical: 12,

    paddingHorizontal: 32,
    borderRadius: 8,
  },
  buttonText: {
    color: '#fff',
    fontSize: 16,
    fontWeight: 'bold',
  },
});
確認ポイント
画面上部にナビゲーションバーが表示される
「商品詳細へ」ボタンで画面が遷移する
「戻る」ボタンまたはナビゲーションバーの左矢印で戻れる
WebのReact Routerとの違い
React Router（Web）	React Navigation
<Link to="/detail">	navigation.navigate('Detail')
useNavigate()	navigation.goBack()
<Route path="...">	<Stack.Screen name="...">
URLベース	画面名ベース

動作確認できたら「演習へ」と教えてください！
