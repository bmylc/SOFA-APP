Claudeが返答しました: レッスン 2-3：FlatList と無限スクロール
レッスン 2-3：FlatList と無限スクロール

前回まで ScrollView + map で商品一覧を作りましたが、商品数が増えるとパフォーマンスが落ちます。FlatList を使うと画面に表示されている部分だけ描画するので、大量データでも快適に動きます。

ScrollView vs FlatList
	ScrollView + map	FlatList
全データを一度に描画	✅ する	❌ しない（必要な分だけ）
大量データのパフォーマンス	❌ 遅くなる	✅ 快適
使い方	シンプル	やや複雑
用途	少量データ	商品一覧など大量データ
FlatList の基本

javascript
import { FlatList } from 'react-native';

<FlatList
  data={products}              // 表示するデータの配列
  keyExtractor={(item) => item.id.toString()} // 各アイテムのユニークなキー
  renderItem={({ item }) => (  // 各アイテムの描画
    <Text>{item.name}</Text>
  )}
/>
2列グリッドにする

numColumns を指定するだけで2列になります。


javascript
<FlatList
  data={products}
  keyExtractor={(item) => item.id.toString()}
  numColumns={2}
  renderItem={({ item }) => (
    <ProductCard item={item} />
  )}

1. context/FavoritesContext.js を作成

javascript
import { createContext, useContext, useState } from 'react';

const FavoritesContext = createContext();

export function FavoritesProvider({ children }) {
  const [favorites, setFavorites] = useState([]);

  const addFavorite = (product) => {
    setFavorites(prev => [...prev, product]);
  };

  const removeFavorite = (id) => {
    setFavorites(prev => prev.filter(item => item.id !== id));
  };

  const isFavorite = (id) => {
    return favorites.some(item => item.id === id);
  };

  return (
    <FavoritesContext.Provider value={{ favorites, addFavorite, removeFavorite, isFavorite }}>
      {children}
    </FavoritesContext.Provider>
  );
}

export function useFavorites() {
  return useContext(FavoritesContext);
}
2. App.js で Provider を使う
