`````text

Claudeが返答しました: レッスン 1-2：JSX と基本コンポーネント
レッスン 1-2：JSX と基本コンポーネント

Web開発の経験があるので、HTMLとの対応関係を意識しながら進めると理解が早いです。

JSX とは

React Native の JSX は React と同じ書き方ですが、HTMLタグの代わりにネイティブコンポーネントを使うのが大きな違いです。

HTML	React Native	用途
<div>	<View>	レイアウト用の箱
<p> <span>	<Text>	テキスト表示
<img>	<Image>	画像表示
<button>	<TouchableOpacity>	タップできる要素
<input>	<TextInput>	テキスト入力
<ul><li>	<FlatList>	リスト表示
基本コンポーネントを触ってみる

App.js を以下に書き換えてください。


javascript
import { View, Text, Image, TouchableOpacity, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>

      {/* テキスト */}
      <Text style={styles.title}>フリマアプリ</Text>

      {/* 画像 */}
      <Image
        source={{ uri: 'https://picsum.photos/200' }}
        style={styles.image}
      />

      {/* ボタン */}
      <TouchableOpacity style={styles.button} onPress={() => alert('タップされました！')}>
        <Text style={styles.buttonText}>商品を見る</Text>
      </TouchableOpacity>

    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#fff',
    alignItems: 'center',
    justifyContent: 'center',
    gap: 16,
  },

  title: {
    fontSize: 24,
    fontWeight: 'bold',
  },
  image: {
    width: 200,
    height: 200,
    borderRadius: 8,
  },
  button: {
    backgroundColor: '#FF6B6B',
    paddingVertical: 12,
    paddingHorizontal: 32,
    borderRadius: 8,
  },
`````
