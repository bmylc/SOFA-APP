Cloud Storageのセキュリティルールを更新する必要があります。今はテストモードで誰でもアクセスできる状態なので、ログイン済みユーザーのみアクセスできるように変更しましょう。

手順

1. Firebaseコンソール → Storage → Rules タブをクリック

2. 現在のルールを以下に書き換える


rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      // ログイン済みユーザーのみ読み書き可能
      allow read, write: if request.auth != null;
    }
  }
}

3. 「公開」ボタンをクリック

合わせてFirestoreのルールも確認

Firestore Database → Rules タブ


rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // 商品：誰でも読める・ログイン済みのみ書ける
    match /products/{productId} {
      allow read: if true;
      allow write: if request.auth != null;
    }

    // チャット：メンバーのみアクセス可能
    match /chats/{chatId} {
      allow read, write: if request.auth != null &&
        resource.data.members.hasAny([request.auth.token.email]);
      
      match /messages/{messageId} {
        allow read, write: if request.auth != null;
      }
    }

    // ユーザー情報：本人のみ書ける・読みは認証済みのみ
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null &&
        request.auth.uid == userId;

      // お気に入りサブコレクション
      match /favorites/{favoriteId} {
        allow read, write: if request.auth != null &&
          request.auth.uid == userId;
      }
    }

    // 通報：ログイン済みのみ作成可能
    match /reports/{reportId} {
      allow read: if false; // アプリからは読まない（GAS経由のみ）
      allow create: if request.auth != null;
      allow update, delete: if false;
    }
  }
}

「公開」ボタンをクリック

設定後の確認
画像アップロードが引き続き動作する
ログインしていない状態では書き込みができない
