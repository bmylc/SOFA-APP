起動後に「SDK Manager」が開くので、以下をインストールしてください。


Android SDK Platform 34
Android SDK Build-Tools
Android Emulator
ステップ 2：環境変数を設定

1. スタートメニューで「環境変数」を検索

2. 「システム環境変数の編集」→「環境変数」

3. 以下を追加


変数名：ANDROID_HOME
変数値：C:\Users\takum\AppData\Local\Android\Sdk

4. Path に以下を追加


%ANDROID_HOME%\platform-tools
%ANDROID_HOME%\tools

5. PowerShellを再起動して確認


powershell
adb --version

バージョンが表示されれば成功です。

ステップ 3：ローカルビルドを実行

powershell
$env:EAS_NO_VCS=1; eas build --platform android --profile preview --local

--local フラグをつけるとクラウドではなくローカルでビルドされます。
